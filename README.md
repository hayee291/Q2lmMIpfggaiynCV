# Q2lmMIpfggaiynCV
* This project is about lothian buses geospatial data analysis.
* In 1st anaylysis a heat map of the speeds of buses on map has been created with red as high speed and green as low speed. It shows that what areas of city are good for fast mobility. Screen shot of that analysis has been uploaded in screenshots directory.
* Second analysis shows buses movement with respect to time which is done through an animator tool in QGIS. A GIF has been uploaded to show it.
* The 3rd analysis shows top 10 SIMD2020 zones with unique number of buses running in them. Base map has been used as Google map. Above that a layer of top 10 semi-transparent zones has been shown with number of unique buses printed in the zone. Screenshot of this analysis has also been uploaded
